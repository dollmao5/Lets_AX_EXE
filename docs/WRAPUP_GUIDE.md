# Round Wrap-up 시스템 — 강사 운영 가이드

> 대상: 교육 진행 강사 / 관리: 과정 개발담당자
> 이 시스템은 Round 1~3 팀 토론의 개인별 제출 → Gemini AI 팀 요약 → 발표 보드 → 차수 누적을 담당합니다.
> 문서 역할 분담: **이 문서 = 강사 PC(bat)·LAN 모드 중심 전체 운영 가이드**, 강사 자료실의 `cohort-guide.html` = 공개 사이트 모드 당일 운영 요약. 두 문서의 라운드 진행 원칙(기록 담당 폐지·전원 제출·라운드마다 [요약 생성] 필수)은 동일합니다.

## 1. 최초 1회 준비 (새 강사 PC, 약 10분)

1. **Node.js 설치**: https://nodejs.org/ko/download → LTS 버전 기본 설치
2. **`AXCAMP_시작.bat` 받기**: 개발담당자에게 사내 채널로 수령 → 바탕화면 등에 보관
   - ⚠️ 이 파일에는 데이터 저장소 접근 열쇠가 들어 있습니다. **사외 전송·외부 공유 금지**
3. bat **더블클릭** → 과정 앱과 지난 차수 데이터가 자동으로 내려오고 서버가 실행됩니다
4. **관리자 계정**: 인수인계받은 관리자 ID/비밀번호로 로그인되는지 확인
   - 관리자 계정이 없으면: 서버 첫 실행 후 가장 먼저 회원가입한 계정이 자동으로 관리자가 됩니다

## 2-B. 외부 교육장 — 공개 사이트로 운영 (강사 PC 서버 없이)

> 사내망 밖 교육장이거나 LAN 구성이 어려울 때. 교육생·강사 모두 **인터넷만 되면** 진행 가능합니다.

1. 교육생·강사 공통 접속 주소: **https://dollmao5.github.io/Lets_AX_EXE** (화이트보드에 게시)
2. 강사: 첫 화면의 **[강사 모드]** 버튼 (또는 **[관리자 모드]** — 둘 다 같은 보드로 연결) → Wrap-up 보드가 새 탭으로 열림 → **[강사 로그인]** → 비밀코드 입력
   - 강사용·관리자용 비밀코드는 개발담당자에게 사내 채널로 수령 (`AXCAMP_instructor_key*.txt` / `AXCAMP_admin_key*.txt`). **사외 공유 금지**
   - 두 코드 모두 보드 관리 기능(차수·차수 코드·요약 생성·제출물 삭제) 사용 가능. 본문 편집·Pages 배포는 여전히 강사 PC 전용
3. (권장) 보드의 **[차수 설정]** 으로 오늘 차수 입력, **[차수 코드]** 로 교육생 제출용 코드 설정
   - 차수 코드를 설정하면 교육생이 첫 제출 때 한 번 코드를 입력합니다 (칠판에 공지) — 외부인 무단 제출 방지
4. 교육생 제출·제출 현황·요약 생성·발표 모드는 아래 3장과 동일하게 진행
   - 요약 생성은 강사 브라우저에서 실행되며 팀 수에 따라 **1~3분** 걸립니다 (AI 혼잡 시 자동 재시도)
5. 데이터는 제출 즉시 원격 저장소(`Lets_AX_Wrapup_DATA`)에 자동 저장됩니다 — push/pull 불필요 (보드에서 해당 버튼이 숨겨짐)
   - 이후 강사 PC(LAN 방식) 교육에서 이 데이터를 이어 쓰려면: 강사 PC 보드에서 **[불러오기(pull)]** 1회
6. (관리자만) **원격 본문 편집**: 학습 화면의 **[관리자 모드]** → 관리자 비밀코드 입력 → 기존과 같은 [본문 수정]·[사이드바 수정] 버튼 사용
   - 저장하면 자동으로 커밋·재배포되어 **약 3~4분 후** 공개 사이트에 반영됩니다 (별도 배포 버튼 불필요)
   - 자산(이미지 등) 업로드는 강사 PC에서만 가능
   - 사전 조건: 공개 레포 편집용 PAT가 Worker에 등록되어 있어야 함 (아래 6장 참고)

## 3. Round 토론 운영 (Round 1·2·3 공통)

| 단계 | 진행 |
|---|---|
| 토론 | 클립 화면의 진행 순서표대로 — **시작 1분 안에 진행자 1명만 지정**, 기록 담당 없음: **전원이 각자 기록·AI Challenge 실행·제출** |
| 제출 | 토론 종료 시: **"각자 화면 아래 '내 논의 내용 제출' 버튼을 눌러주세요"** — 처음 한 번만 자기 팀(1~6팀)과 이름 선택 |
| 현황 확인 | 보드 상단 "제출 현황: 1팀 4명 · 2팀 3명…" — 늦는 팀만 독려 |
| 요약 생성 | **라운드마다 필수** — 보드에서 해당 Round 탭 선택 → **[요약 생성]** 클릭 → 공개 사이트 1~3분 / 강사 PC 30초~1분 대기. (다음 라운드·CH04 실습이 이 결과의 토론 정리본을 입력으로 사용합니다) |
| 팀 발표 | **[발표 모드 ▶]** 클릭 → 빔프로젝터 전체화면 → 팀별 발표자가 자기 팀 화면을 보며 1~2분 발표 (→ 키로 다음 팀) |
| 강사 마무리 | 마지막 슬라이드 **교차 분석**(공통 긴장 TOP 3·팀별 차이·마무리 멘트 제안)으로 Wrap-up |

- 지난 차수 소개: 보드의 **차수 보기** 드롭다운에서 지난 차수 선택 → "지난 기수 팀장들은 이런 고민을 했습니다"
- 차수가 쌓이면 요약에 **차수 비교**(반복 고민 vs 새 관점)가 자동 포함됩니다

## 3-B. 개인별 토론 정리본 (팀 합의 + 개인 원문 병합 — 다음 실습의 개인 자료)

개인별 토론 정리본이 만들어집니다 (AI 호출 없는 즉시 병합 — 비용·대기 없음, 재실행 안전).

## 5. 문제 해결

| 증상 | 조치 |
|---|---|
| 교육생이 접속 안 됨 | ① 같은 Wi-Fi/네트워크인지 확인 ② 강사 PC Windows 방화벽에서 Node.js 허용 (제어판→방화벽→앱 허용) ③ 주소의 IP를 다시 확인 (bat 창에 표시) |
| "요약 생성" 실패 | AI 혼잡 시 자동으로 2회 재시도 후 간이(lite) 모델로 대체됩니다 (로컬·공개 사이트 공통). 그래도 실패하면 인터넷 연결 확인 후 [요약 생성] 재실행. 계속 실패 시: 팀 카드 없이도 교육은 진행 가능 — 팀별 구두 발표로 전환하고 종료 후 개발담당자에게 연락 |
| 제출이 안 됨 (공개 사이트) | "차수 코드가 필요합니다" 표시 → 칠판에 공지한 차수 코드 입력 안내. 보드에서는 현재 코드를 확인할 수 없습니다 — 기억나지 않으면 [차수 코드]에서 새 코드로 재설정하고 칠판에 다시 공지하세요 |
| 요약 생성이 느리거나 일부 팀 실패 (공개 사이트) | AI 무료 등급 혼잡입니다. 1~2분 후 [요약 생성] 재실행 — 성공한 팀 요약은 유지되지 않고 새로 생성되므로 전체 재실행하면 됩니다 |
| bat 실행 시 내려받기 실패 | 토큰 만료 가능성 → 개발담당자 연락 (기존에 받은 폴더가 있으면 그대로 실행은 가능) |
| 서버 창을 실수로 닫음 | bat 다시 더블클릭 (데이터는 보존됨) |
| 잘못된 제출물·테스트 제출 삭제 | 보드 상단 제출 명단에서 해당 이름 칩의 **✕ 클릭**(토론 정리본 동반 삭제) · 같은 이름 재제출은 자동 덮어쓰기라 삭제 불필요 · 이미 요약을 만들었다면 [요약 생성] 재실행 |

## 6. 개발담당자 관리 항목 (강사 아님)

- **토큰 관리**: 데이터 저장소 토큰(fine-grained, `Lets_AX_Wrapup_DATA` 한정) 만료 전 갱신 → `node scripts/make-launcher.mjs`로 bat 재생성 → 재배포. 발급 절차: GitHub Settings → Developer settings → Fine-grained tokens (Contents: Read and write만)
- **Gemini 키 관리**: 키 파일 `Google AI Studio_API key*.txt`를 저장소 폴더에 유지 (gitignore 보호). 교체 시 파일 내용만 갱신. 발급: https://aistudio.google.com → Get API key. **키 교체 후에는 `node scripts/deploy-worker.mjs` 1회 실행** (공개 사이트용 Worker 시크릿도 함께 갱신됨)
- **Cloudflare Worker 관리 (공개 사이트 제출·보드 백엔드)**: 코드는 `cloudflare/worker.js`, 배포는 `node scripts/deploy-worker.mjs` (계정 정보 `cloudflare*.txt`, 강사 비밀코드 `AXCAMP_instructor_key*.txt`, 관리자 비밀코드 `AXCAMP_admin_key*.txt` — 모두 gitignore 보호). GitHub PAT·Gemini 키·강사/관리자 코드가 Worker 시크릿으로 올라가며, 토큰 갱신 시에도 같은 명령 1회면 됩니다. 주소: https://axcamp-wrapup.dollmao5.workers.dev (무료 플랜, 일 10만 요청)
- **원격 본문 편집용 PAT**: 공개 레포(`Lets_AX_EXE`) 한정 fine-grained PAT (Contents: Read and write) 발급 → 파일명에 `exe`가 들어간 txt로 저장소 폴더에 저장 (예: `Github_Fine-grained_exe-edit_key_YYMMDD.txt`) → `node scripts/deploy-worker.mjs` 실행 시 `PUBLIC_REPO_TOKEN` 시크릿으로 자동 등록. 이 토큰이 없으면 공개 사이트 관리자 본문 편집만 비활성 (다른 기능은 무관)
- **원격 편집 처리 구조**: 관리자 저장 → Worker가 공개 레포 `.edit-queue/`에 요청 커밋 → GitHub Actions(`apply-edits.yml`)가 server.js 로직으로 적용(md/txt/metadata 재생성 동일) → 적용 커밋 push + Pages 재배포 자동 실행
- **bat 재생성**: `node scripts/make-launcher.mjs` — 토큰 파일에서 자동 주입, 산출물은 gitignore
- **환경변수 오버라이드** (선택): `GEMINI_API_KEY`, `GEMINI_MODEL`(기본 gemini-3.5-flash), `WRAPUP_GIT_TOKEN`, `WRAPUP_GIT_REMOTE`
- **데이터 위치**: `data/wrapup/{차수}/{round}/` (개인별 토론 정리본은 그 아래 `canvas2/` — 내부 폴더명은 구 명칭 canvas2 유지) — `data/`는 gitignore라 공개 저장소·Pages에 절대 올라가지 않음. 원격 백업은 프라이빗 저장소 `dollmao5/Lets_AX_Wrapup_DATA` (동일 레이아웃이라 pull/push 동기화에 canvas2도 포함됨)

```
[금지] 실명(본인 외)·평가·보상·고객 식별 정보 입력 금지
```
