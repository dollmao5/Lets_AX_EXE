2. 추가 요청: SSL 검사(HTTPS 복호화) 예외 및 인증서 폐기 확인 (2026-08-06)

증상 — 교육·운영 PC에서 브라우저는 위 사이트에 접속되지만, Windows 표준 TLS를 쓰는 도구(curl, Node.js 등)는 CRYPT_E_NO_REVOCATION_CHECK 오류로 연결이 거부됩니다.

원인 (2026-08-06 실측) — 사내망 SSL 검사 장비가 HTTPS를 복호화한 뒤 사내 CA로 재서명하는데, 이때 재발급되는 인증서에 폐기 확인 정보(CRL 배포 지점·OCSP 주소)가 포함되어 있지 않습니다. Windows(schannel)는 인증서의 폐기 여부를 확인하지 못하면 연결을 거부하므로 접속이 실패합니다.

요청 (택 1)
  1. (권장) 위 표의 필수 도메인들을 SSL 검사(복호화) 예외 목록에 추가 — 원본 인증서가 그대로 전달되어 폐기 확인이 정상 동작하며, 파일 업로드 등 실습 기능 오작동 예방에도 도움이 됩니다.
  2. (대안) SSL 검사 장비가 재발급하는 인증서에 사내 CA의 CRL/OCSP 주소를 포함하도록 설정하고, 해당 사내 폐기 확인 서버로의 접근을 허용

참고 — 1번 적용 시 함께 허용 필요한 공인 CA 폐기 확인 도메인 (OCSP/CRL은 HTTP 80 포트 사용이 일반적)
