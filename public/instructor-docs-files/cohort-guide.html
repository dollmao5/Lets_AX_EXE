「리더십 향상 with AI」 차수 전환 강사 가이드

차수마다 강사·PC가 바뀌어도 이 문서 하나로 준비 완료 · 2026-08-06 · 운영: HRD담당/리더십개발팀

0. 시스템 한눈에 보기

  • 강사·교육생 모두 개인 PC 브라우저로 접속합니다. 설치할 프로그램은 없습니다.
    • 교육생(학습 포털): https://dollmao5.github.io/Lets_AX_EXE
    • 강사(Wrap-up 보드): https://dollmao5.github.io/Lets_AX_EXE/wrapup.html
  • 팀 제출·요약·토론 정리본은 모두 원격 저장소에 자동 저장됩니다. 강사 PC에는 아무것도 남지 않으며, PC가 바뀌어도 데이터는 그대로입니다.
  • 강사가 새 PC에서 입력할 것은 강사 비밀코드 1회뿐입니다. (AI 요약용 키는 자동 공급 — 입력 불필요)

1. 교육 전날까지 (사전 준비)

확인내용
① 접속 확인강사 PC 브라우저에서 위 두 주소가 열리는지 확인 (사내망이면 dollmao5.github.io · axcamp-wrapup.dollmao5.workers.dev 허용 필요)
② 사내망 예외 요청사내망 PC로 진행하는 차수라면 IT/보안 부서에 실습 도메인 허용과 SSL 검사(HTTPS 복호화) 예외를 함께 요청합니다 — 요청용 도메인 목록·요청 문구는 별도 문서 「사내망 해제 요청 사이트 목록」 참조 (운영 담당자가 대행 가능). SSL 검사 예외가 없으면 브라우저 접속은 되어도 파일 업로드 등 일부 기능이 오작동할 수 있습니다
③ 비밀코드 수령운영 담당자에게 강사 비밀코드를 전달받습니다
④ (선택) 리허설리허설이 필요하면 임시 차수 이름(예: rehearsal)으로 아래 2번 절차를 미리 연습합니다. 당일 아침 실제 차수로 전환하면 리허설 데이터와 섞이지 않습니다

2. 교육 당일 아침 — 차수 전환 절차 (보드에서, 하루 1회)

  1. 강사 로그인 — wrapup.html 접속 → 강사 비밀코드 입력 (새 PC당 1회. 이후 관리 버튼이 나타납니다)
  2. 차수 설정 — 오늘 차수 이름 등록 (예: 2026-08-21차수). 오늘의 모든 제출·요약·토론 정리본이 이 이름 아래에 저장됩니다. 하루 1회, 가장 먼저.
  3. 차수 코드 (선택) — 두 가지 중 선택:
    • 코드 설정: 칠판·화면에 코드를 공지 → 교육생은 최초 제출 시 1회 입력 (외부인 제출 차단)
    • 빈 값으로 저장: 교육생은 아무 코드 입력 없이 제출 (무입력 운영)
  4. 반영 확인 — 교육생 화면에서 테스트 제출 1건 → 보드 새로고침으로 제출 숫자가 오르는지 확인

3. 수업 중 (라운드 운영 요약)

기억할 것은 한 줄: 차수 설정 → (토론·제출 확인) → [요약 생성] → 발표 모드 → [토론 정리본 생성]
  • [요약 생성]은 라운드(R1·R2·R3)마다 필수입니다 — 여기서 만든 요약·토론 정리본이 다음 라운드와 CH04 NotebookLM 실습의 소스가 됩니다.
  • 자세한 버튼별 사용법은 보드 상단 사용법 ❓ 와 도입·마무리 🎬 에 있습니다.

4. 교육 종료 후

  • 강사는 할 일이 없습니다. 데이터는 이미 원격 저장소에 저장되어 있습니다.
  • 자료 회수는 운영 담당자가 합니다: 개발 PC 로컬 보드에서 불러오기(pull) → zip 내보내기 두 클릭.

5. 문제가 생기면

증상조치
제출 숫자가 안 올라감보드 [새로고침] → 차수 이름·차수 코드가 교육생 안내와 일치하는지 확인
요약 생성 실패·지연한 번 더 실행 (재실행 안전). AI 호출이 막히면 자동으로 간이(lite) 요약으로 대체됨
보드·사이트 전체 장애교육생에게 각자 캔버스의 [Markdown 다운로드] 백업을 안내하고, 팀별 구두 발표로 전환해 수업 계속 진행
강사 PC 교체(수업 중 포함)새 PC에서 비밀코드만 다시 입력 — 데이터·설정은 그대로 이어짐
