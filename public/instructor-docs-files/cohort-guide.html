1️⃣ 교육 전날까지 — 사전 준비

확인내용
① 접속 확인강사 PC 브라우저에서 위 두 주소가 열리는지 확인하고,
실습 사이트(chatgpt.com · notebooklm.google.com · accounts.google.com)도 함께 열어봅니다
(사내망이면 dollmao5.github.io · axcamp-wrapup.dollmao5.workers.dev를 포함한 전체 목록 허용 필요 — 「사내망 해제 요청 사이트 목록」 참조)
② 사내망 예외 요청사내망 PC로 진행하는 차수라면 IT/보안 부서에 실습 도메인 허용과 SSL 검사(HTTPS 복호화) 예외를 함께 요청합니다
— 요청용 도메인 목록·요청 문구는 별도 문서 「사내망 해제 요청 사이트 목록」 참조 (운영 담당자가 대행 가능).
SSL 검사 예외가 없으면 브라우저 접속은 되어도 파일 업로드 등 일부 기능이 오작동할 수 있습니다
③ 비밀코드 수령리더십개발팀 담당자에게 문의하여 강사 비밀코드를 전달받습니다
④ (선택) 리허설리허설이 필요하면 임시 차수 이름(예: rehearsal)으로 아래 2번 절차를 미리 연습합니다.
당일 아침 실제 차수로 전환하면 리허설 데이터와 섞이지 않습니다
⑤ 보드 D-1 체크리스트Wrap-up 보드 [도입·마무리 🎬]의 D-1 체크리스트 수행 (QuizN 보드 초기화·생각 열기 링크 확인 등)

2️⃣ 교육 당일 아침 — 차수 전환 절차 (보드에서, 하루 1회)

🧑‍🏫 강사 로그인

wrapup.html 접속 → 강사 비밀코드 입력 (새 PC당 1회 — 이후 관리 버튼이 나타납니다)
※ 비밀코드를 모르시면 리더십개발팀 담당자에게 문의해 주세요

차수 설정 — 오늘 차수 이름 등록

예: 2026-08-21차수. 오늘의 모든 제출·요약·토론 정리본이 이 이름 아래에 저장됩니다. 하루 1회, 가장 먼저.

차수 코드 — 선택 사항
  • 코드 설정: 칠판·화면에 코드를 공지 → 교육생은 최초 제출 시 1회 입력 (외부인 제출 차단 🔒)
  • 빈 값으로 저장: 교육생은 아무 코드 입력 없이 바로 제출할 수 있습니다 (간편 운영 ✨)
✅ 반영 확인

교육생 화면에서 테스트 제출 1건 → 보드 새로고침으로 제출 숫자가 오르는지 확인

3️⃣ 수업 중 — 라운드 운영

차수 설정→ 토론·제출 확인→ 요약 생성→ 발표 모드→ 토론 정리본 생성
  • [요약 생성]은 라운드(R1·R2·R3)마다 필수입니다 — 여기서 만든 요약·토론 정리본이 다음 라운드와 CH04 NotebookLM 실습의 소스가 됩니다.
  • 자세한 버튼별 사용법은 보드 상단 사용법 ❓ 와 도입·마무리 🎬 에 있습니다.

4️⃣ 교육 종료 후

✅ 따로 저장하거나 정리하실 일이 없습니다.
수업 중 만들어진 팀 제출·요약·토론 정리본은 모두 원격 저장소에 자동 저장되어 있으니, 편안하게 마무리하시면 됩니다.

📦 자료 회수는 운영 담당자가 진행합니다 — 개발 PC 로컬 보드에서 불러오기(pull) → zip 내보내기 두 클릭이면 됩니다.

5️⃣ 문제가 생기면 — 응급 대응

증상조치
😕 제출 숫자가 안 올라감보드 [새로고침] → 차수 이름·차수 코드가 교육생 안내와 일치하는지 확인
⏳ 요약 생성 실패·지연한 번 더 실행 (재실행 안전). AI 호출이 막히면 자동으로 간이(lite) 요약으로 대체됨
🚨 보드·사이트 전체 장애교육생에게 각자 캔버스의 [Markdown 다운로드] 백업을 안내하고, 팀별 구두 발표로 전환해 수업 계속 진행
