📖 Wrap-up 보드 사용법 (강사용)

각 버튼의 역할과 누르는 시점을 교육 흐름 순서로 정리했습니다. ESC 또는 바깥 클릭으로 닫힙니다.

오늘 하루 흐름 (이 순서대로만 누르면 됩니다)

  1. 교육 시작 전차수 설정 — 오늘 차수 이름을 등록합니다 (예: 2026-09-03차수). 오늘의 모든 제출·요약이 이 이름 아래에 저장됩니다. 하루 1회, 가장 먼저.
  2. 교육 시작 전 · 선택차수 코드 — 공개 사이트라 아무나 제출할 수 있으므로, 제출용 코드를 정해 칠판·화면에 공지합니다. 외부인 제출을 막는 자물쇠입니다. 빈 값으로 저장하면 코드 없이 제출 가능.
  3. Round 토론 중 버튼 조작 없음 — 교육생이 각자 클립 화면에서 제출하면 상단 "제출 현황: 1팀 4명 · 2팀 3명 … (총 N명)"이 올라갑니다. 제출 현황은 30초마다 자동 갱신됩니다(즉시 확인은 새로고침). 늦는 팀만 독려하세요.
  4. 제출 마감 직후요약 생성 — AI가 팀별 요약(핵심 논점·발표 포인트·관점 차이)과 전체 교차 분석을 만듭니다. 30초~수분 소요. 재실행하면 새로 생성되므로 늦은 제출자가 있으면 다시 눌러도 됩니다.
  5. 요약 생성 후발표 모드 ▶ — 빔프로젝터 전체화면으로 전환해 팀별 발표를 진행합니다 (←/→ 이동, ESC 종료). 마지막 교차 분석 슬라이드로 강사 Wrap-up.
  6. 요약 생성 후토론 정리본 생성 — 제출자 전원에게 개인별 토론 정리본(① 내 결론 우선 ② 팀 공통 합의 ③ 관점 차이)를 만들어 줍니다. 교육생은 다음 Round 화면의 "📌 Round 1·2 내 토론 정리본 불러오기" 패널에서 참고하고, CH04에서 통합본(.md)을 받아 NotebookLM 소스로 씁니다. AI 호출 없이 즉시 처리되며 몇 번 눌러도 안전합니다. 깜빡해도 괜찮습니다 — 교육생이 조회하면 자동으로 즉석 생성됩니다 (단, 요약 생성 전에는 '팀 합의' 부분이 비어 있음).
  7. 교육 종료저장·백업(push) — 오늘 차수 데이터를 원격 저장소에 백업합니다. 하루 1회, 마지막에.

과정 전체 Flow — 이 보드가 어디에 끼어 있나

CH01AI 핵심 개념 (강의·퀴즈) — 산출물 없음
CH02ChatGPT 실습: Round 1(이 보드) → 리더 역할 프로필 → Round 2(이 보드) → 역량 브리프 → 통합 Gate
CH03ChatGPT 실습: 팀 진단 2종 → Round 3(이 보드) → 통합 Gate
CH04NotebookLM 실습: CH02·CH03 Gate 통합본 + R1~3 토론 정리본 통합본(이 보드에서 생성)을 소스로 30일 실행계획 작성
CH05산출물 회수 + Start·Stop·Continue Wrap-up

즉, 이 보드는 Round 1·2·3 세 번 쓰이고, 여기서 만든 요약·토론 정리본이 CH04 실습의 소스로 이어집니다. 탭 아래 녹색 띠에서 현재 단계와 다음 단계를 항상 확인할 수 있습니다.
