📖 Wrap-up 보드 사용법 (강사용)

각 버튼의 역할과 누르는 시점을 교육 흐름 순서로 정리했습니다. ESC 또는 바깥 클릭으로 닫힙니다.

오늘 하루 흐름 (이 순서대로만 누르면 됩니다)

  1. 교육 시작 전차수 설정 — 오늘 차수 이름을 등록합니다 (예: 2026-09-02차수). 오늘의 모든 제출·요약이 이 이름 아래에 저장됩니다. 하루 1회, 가장 먼저.
  2. 교육 시작 전 · 선택차수 코드 — 공개 사이트라 아무나 제출할 수 있으므로, 제출용 코드를 정해 칠판·화면에 공지합니다. 외부인 제출을 막는 자물쇠입니다. 빈 값으로 저장하면 코드 없이 제출 가능.
  3. Round 토론 중 버튼 조작 없음 — 교육생이 각자 클립 화면에서 제출하면 상단 "제출 현황: 1조 4명 · 2조 3명…"이 올라갑니다. 새로고침으로 갱신하며 늦는 팀만 독려하세요.
  4. 제출 마감 직후요약 생성 — AI가 팀별 요약(핵심 논점·발표 포인트·관점 차이)과 전체 교차 분석을 만듭니다. 30초~수분 소요. 재실행하면 새로 생성되므로 늦은 제출자가 있으면 다시 눌러도 됩니다.
  5. 요약 생성 후발표 모드 ▶ — 빔프로젝터 전체화면으로 전환해 팀별 발표를 진행합니다 (←/→ 이동, ESC 종료). 마지막 교차 분석 슬라이드로 강사 Wrap-up.
  6. 요약 생성 후2차 캔버스 생성 — 제출자 전원에게 개인별 2차 캔버스(① 내 결론 우선 ② 팀 공통 합의 ③ 관점 차이)를 만들어 줍니다. 교육생은 다음 Round 화면에서 "이전 Round 2차 캔버스 불러오기"로 참고하고, CH04에서 통합본(.md)을 받아 NotebookLM 소스로 씁니다. AI 호출 없이 즉시 처리되며 몇 번 눌러도 안전합니다. 깜빡해도 괜찮습니다 — 교육생이 조회하면 자동으로 즉석 생성됩니다 (단, 요약 생성 전에는 '팀 합의' 부분이 비어 있음).
  7. 교육 종료저장·백업(push) — 오늘 차수 데이터를 원격 저장소에 백업합니다. 하루 1회, 마지막에.

과정 전체 Flow — 이 보드가 어디에 끼어 있나

CH01AI 핵심 개념 (강의·퀴즈) — 산출물 없음
CH02ChatGPT 실습: Round 1(이 보드) → 리더 역할 프로필 → Round 2(이 보드) → 역량 브리프 → 통합 Gate
CH03ChatGPT 실습: 팀 진단 2종 → Round 3(이 보드) → 통합 Gate
CH04NotebookLM 실습: CH02·CH03 Gate 통합본 + R1~3 2차 캔버스 통합본(이 보드에서 생성)을 소스로 30일 실행계획 작성
CH05산출물 회수 + Start·Stop·Continue Wrap-up

즉, 이 보드는 Round 1·2·3 세 번 쓰이고, 여기서 만든 요약·2차 캔버스가 CH04 실습의 소스로 이어집니다. 탭 아래 녹색 띠에서 현재 단계와 다음 단계를 항상 확인할 수 있습니다.

🎬 클립별 도입 훅 (강사용)

각 클립 시작 전 2~3분 환기용 시나리오입니다. 교육생 화면의 접이식 "🎬 강사 도입 자료" 블록에는 링크만 있고, 멘트·반전·수치는 여기에만 있습니다.

공통 원칙 3가지

  1. 수치·사건만 던지고, 해석과 답은 팀에 맡깁니다. 훅이 답의 예시가 되면 토론이 좁아집니다.
  2. 반전(Klarna 재고용, 퀴즈 정답)은 미리 말하지 않습니다. 교육생이 링크를 미리 봤어도 모른 척 진행하면 됩니다.
  3. 훅은 2~3분입니다. 길어지면 실습 시간을 잠식합니다 — Round 훅은 팀들이 역할을 정하는 첫 3분과 병행하세요.
