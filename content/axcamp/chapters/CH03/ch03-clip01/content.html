조직 역량 점검 및 Workflow 재설계

본 모듈은 CH02에서 정리한 AI 시대 팀 리더 역할과 핵심 역량 프로필을 참고하되, 이번에는 관점을 리더 개인에서 조직(팀)의 성과 창출 구조로 확장하는 실습입니다.
CH02가 “나는 어떤 리더가 되어야 하는가?”를 다뤘다면, CH03은 “우리 팀은 성과를 내는 구조로 일하고 있는가?”를 점검합니다.

이번 실습은 단순히 프롬프트를 복사해 붙여넣고 결과를 받는 방식이 아닙니다. Gemini가 질문하고, 팀장이 답변하고, 다시 Gemini가 중간 정리와 보강 질문을 이어가며 팀 성과 병목 진단 리포트, 팀 효과성 지표, 조직/인재 행동역량 프로파일, Workflow Re-design Canvas를 완성하는 구조화된 대화형 실습입니다.

Step 1. 팀 현황/이슈 인식

우리 팀의 성과관리 및 비효율 상황을 정의합니다. 처음부터 완성된 문제 진술을 쓰려고 하지 말고, 실제로 반복되는 문제를 자연스럽게 말하는 것부터 시작합니다.

대화형 실습 1-1. 대화 시작 템플릿
당신은 조직 진단 및 성과관리 컨설팅 분야의 전문가이자, 나의 조직 진단 인터뷰어입니다. 나는 지금 우리 팀의 성과 창출을 방해하는 문제를 구조적으로 진단하려고 합니다. 내가 현업에서 실제로 겪고 있는 문제를 편하게 이야기하면, 단순한 개인 간 갈등이나 커뮤니케이션 문제가 아니라 우리 팀의 성과 체계 안에 있는 구조적 병목 요인을 찾을 수 있도록 질문을 이어가 주세요. 특히 아래 관점이 자연스럽게 드러나도록 도와주세요. - 목표와 성과 기준이 명확한가? - 역할, 책임, 의사결정 권한이 명확한가? - 업무 절차, 회의, 보고, 검토 방식이 효과적인가? - 팀 내 신뢰, 피드백, 갈등관리 방식이 건강한가? - 팀원들이 우려, 반대 의견, 실패 가능성을 조기에 말할 수 있는가? - 약속한 일을 예측 가능하게 수행하고 있는가? 조건: - 질문은 한 번에 1~2개씩만 해주세요. - 답변이 추상적이면 실제 회의, 보고, 업무지시, 검토, 마감 상황으로 바꿔 질문해 주세요. - 빠진 정보는 추정하지 말고 질문으로 보완해 주세요. - 중간중간 “현재까지 정리된 우리 팀 병목”을 3줄로 업데이트해 주세요. - 평가, 보상, 징계, 개인정보와 관련된 민감한 내용은 익명화하거나 일반화해서 다루도록 안내해 주세요. - 아직 최종 리포트를 쓰지 말고, 먼저 나에게 질문을 이어가 주세요. 먼저 우리 팀에서 반복되는 문제를 편하게 이야기해보겠습니다.
이어서형 실습 1-2. 팀 성과 병목 진단 리포트 요청
지금까지 나눈 대화를 바탕으로, 우리 팀의 성과관리 및 비효율 상황을 구조적으로 정리해 주세요. 출력 형식은 아래와 같이 해 주세요. ## 1. 문제 상황 요약 - 리더가 입력한 내용을 3~5줄로 요약해 주세요. ## 2. 표면 증상과 구조적 병목 구분 | 표면 증상 | 구조적 병목 가능성 | 성과에 미치는 영향 | |---|---|---| ## 3. Root Cause 진단 리포트 | 근본 원인 | 관련 진단 관점 | 왜 이것이 문제인가 | 성과 영향 | 근거 수준 | 방치 시 리스크 | |---|---|---|---|---|---| ## 4. 리더가 추가로 확인해야 할 질문 - 목표 기준 측면: - 역할/R&R 측면: - 프로세스 측면: - 관계/피드백 측면: - 심리적 안전감 측면: - 실행 신뢰성 측면: 조건: - 추상적인 조언보다 실제 업무 장면 중심으로 분석해 주세요. - 근거 수준은 “리더 입력 근거 있음 / 추론 / 추가 확인 필요” 중 하나로 표시해 주세요. - 정보가 부족한 부분은 “리더 확인 필요”라고 표시해 주세요. - 개인 실명, 평가, 보상, 징계, 개인정보와 관련된 내용은 익명화·일반화해서 다루어 주세요.

대화형 실습 2-1. 지표 설계 인터뷰 요청
방금 Step 1에서 작성한 Root Cause 진단 리포트를 바탕으로, 우리 팀의 성과향상 여부를 확인할 수 있는 팀 효과성 지표를 설계하려고 합니다. 이번에도 바로 최종 표를 만들지 말고, 먼저 나에게 지표 설계를 위한 질문을 해 주세요. 아래 프레임워크를 기준으로 질문해 주세요. - GRPI: Goals, Roles, Processes, Interpersonal - Project Aristotle: Psychological Safety, Dependability, Structure & Clarity 조건: - 질문은 한 번에 1~2개씩만 해 주세요. - 각 질문 옆에 “이 질문이 필요한 이유”를 한 줄로 적어 주세요. - 지표는 30일 안에 관찰 가능한 정량/정성 지표로 설계해 주세요. - “소통 강화”, “협업 강화”처럼 추상적인 표현은 지표로 인정하지 말고, 관찰 가능한 행동이나 산출물 기준으로 바꿔 주세요. - 팀 단위 패턴을 보되, 개인 식별이나 평가·보상에 직접 연결되는 방식은 피해주세요. 먼저 Step 1의 Root Cause를 기준으로 어떤 차원부터 지표화해야 할지 질문해 주세요.

Step 3. 조직/인재 행동역량 정의

Step 2에서 확인한 취약 지표를 개선하기 위해 필요한 조직/인재 행동역량을 정의합니다. CH02처럼 리더 개인의 역할을 다시 쓰는 것이 아니라, 팀 성과 병목을 해결하기 위한 리더·팀원·팀 공통 행동 기준을 만듭니다.

대화형 실습 3-1. 행동역량 설계 인터뷰 요청
방금 Step 2에서 도출한 우리 팀의 효과성 지표와 최우선 개선 차원을 바탕으로, AI 시대 성과향상에 필요한 우리 조직(팀)/인재 행동역량을 정의하려고 합니다. 주의할 점은, 이번 단계는 리더 개인의 역량을 다시 정의하는 시간이 아닙니다. CH02에서 리더 개인의 역할과 핵심 역량은 이미 정리했습니다. 이번에는 우리 팀이 성과를 내는 구조로 일하기 위해, 리더와 팀원, 그리고 팀 공통으로 어떤 행동역량이 필요한지 대화형으로 정리해 주세요. 먼저 아래 관점에서 나에게 질문해 주세요. - Step 2에서 도출한 취약 지표 중 가장 먼저 개선해야 할 것은 무엇인가? - 그 지표가 개선되려면 팀원의 어떤 행동이 달라져야 하는가? - 리더는 어떤 기준과 환경을 제공해야 하는가? - AI를 활용할 때 팀원에게 필요한 최소 역량은 무엇인가? - 보안, 개인정보, 평가정보와 관련해 반드시 지켜야 할 기준은 무엇인가? 조건: - 질문은 한 번에 1~2개씩만 해 주세요. - 답변이 추상적이면 실제 업무 장면으로 바꿔 질문해 주세요. - “좋은 태도”가 아니라 관찰 가능한 행동 기준으로 정리해 주세요. - 중간중간 “현재까지 정리된 우리 팀 필요 행동역량”을 3줄로 업데이트해 주세요.

Step 4. Workflow Re-design

대표 비효율 업무 1개를 선정해 Divide-Navigate-Arrange 3단계로 재설계합니다. 이 단계에서도 Gemini와 대화하며 업무를 고르고, Task를 분해하고, AI 적합도와 인간 책임을 확인합니다.

대화형 실습 4-1. 대표 업무 선택 대화 시작
이제 우리 팀의 대표 비효율 업무 1개를 선정해 Workflow Re-design을 진행하려고 합니다. 앞서 Step 1~3에서 도출한 내용은 다음과 같습니다. - 우리 팀의 성과관리 및 비효율 상황 - Root Cause 기반 구조적 병목 - GRPI / Project Aristotle 기반 팀 효과성 지표 - 취약 지표를 해결하기 위한 조직/인재 행동역량 이번 단계에서는 바로 Canvas를 만들지 말고, 먼저 내가 재설계할 대표 업무를 고를 수 있도록 질문해 주세요. 대표 업무 후보 예시는 다음과 같습니다. - 월간 성과 보고서 작성 및 취합 - 고객 요구사항 대응 및 데이터화 - 주간 업무회의 준비 - 프로젝트 리스크 점검 - 평가면담 사전자료 정리 - 신규 과제 검토 보고서 작성 - VOC 분석 및 개선 과제 도출 조건: - 나에게 한 번에 1~2개 질문만 해 주세요. - 어떤 업무를 고르면 학습 효과가 큰지 판단 기준을 제시해 주세요. - 업무 선정 기준은 반복성, 시간 소요, 품질 편차, R&R 갈등, AI 활용 가능성, 보안 리스크를 포함해 주세요. - 내가 업무를 선택하면, 다음 단계에서 Divide를 진행할 수 있도록 현재 업무 흐름을 질문해 주세요.
대화형 실습 4-2. Divide - 업무 분해 대화
내가 선택한 대표 업무를 기준으로 Divide를 진행해 주세요. 단, 바로 완성표를 만들기 전에 내가 실제 업무 흐름을 설명할 수 있도록 질문을 먼저 해 주세요. 질문 기준: - 이 업무는 언제 시작되고 언제 끝나는가? - 누가 어떤 정보를 제공하는가? - 중간에 누구의 검토나 승인이 필요한가? - 시간이 가장 많이 걸리는 단계는 어디인가? - 품질 문제가 자주 생기는 단계는 어디인가? - R&R 갈등이나 업무 공백이 생기는 단계는 어디인가? - 팀장이 직접 다시 수정하거나 판단하는 단계는 어디인가? 조건: - 질문은 한 번에 1~2개씩만 해 주세요. - 내가 답변하면 현재까지 파악한 업무 흐름을 6~12개 Task 초안으로 정리해 주세요. - 불확실한 Task는 “리더 확인 필요”라고 표시해 주세요.
이어서형 실습 4-3. Navigate - AI 적합도 매핑
지금까지 정리한 Task 분해 초안을 바탕으로 Navigate를 진행해 주세요. 각 Task별로 AI 적용 적합도를 High / Medium / Low / No로 판단하고, AI 강점 관점에서 “발견 / 신뢰 / 부적합” 중 어디에 해당하는지 구분해 주세요. 또한 각 Task에서 사용하는 데이터의 보안 민감도를 아래 기준으로 분류해 주세요. - 공개 가능 - 내부자료 - 민감정보 - AI 입력 금지 출력 형식: ## Task별 AI 적합도 매핑 | Task 번호 | 세부 과업 | AI 적합도 | AI 강점 구분: 발견/신뢰/부적합 | 판단 사유 | 데이터 민감도 | 리더 확인 필요 사항 | |---|---|---|---|---|---|---| 조건: - AI가 모든 일을 대신한다는 표현은 사용하지 마세요. - AI는 초안, 요약, 비교, 분류, 패턴 탐색, 시뮬레이션을 지원하는 도구로 설정해 주세요. - 평가, 보상, 징계, 개인정보, 민감 영업정보가 포함되는 Task는 보수적으로 판단해 주세요. - AI 입력 금지에 해당하는 데이터가 있으면 명확히 표시해 주세요.
이어서형 실습 4-4. Arrange - 책임·검증·Fallback 설계
이제 Navigate 결과를 바탕으로 Arrange를 진행해 주세요. 목적은 AI와 인간의 역할을 재배치하는 것입니다. 각 Task별로 AI가 만들 수 있는 산출물, 사람이 검증해야 할 지점, 리더가 최종 책임져야 할 판단, AI 실패 시 대안을 정리해 주세요. 출력 형식: ## Arrange: AI 협업 구조 재배치 | Task 번호 | AI 활용 방식 | AI 산출물 기준 | 인간 검증 포인트 | 리더의 최종 책임 | Fallback Plan | |---|---|---|---|---|---| 조건: - 목표 기준 설정, 최종 판단, 평가, 보상, 징계, 민감한 피드백은 리더의 최종 책임으로 명확히 구분해 주세요. - AI 산출물 기준은 형식, 정확성, 근거, 누락 여부, 보안 기준을 포함해 주세요. - Fallback Plan은 AI를 사용할 수 없거나 결과 품질이 낮을 때의 수동 대안으로 작성해 주세요.
이어서형 실습 4-5. Workflow Re-design Canvas 완성
지금까지 대화한 Divide, Navigate, Arrange 결과를 바탕으로 최종 Workflow Re-design Canvas를 작성해 주세요. 출력 형식은 아래와 같이 해 주세요. ## Workflow Re-design Canvas | 항목 | 작성 내용 | |---|---| | 업무명 | | | 고객/사용자 가치 | | | 현재 핵심 비효율 | | | 재설계 방향 | | | Task 분해 요약 | | | AI 적합 Task | | | AI에게 맡기면 안 되는 Task | | | 데이터 민감도 및 보안 주의사항 | | | AI 산출물 형식 | | | AI 산출물 품질 기준 | | | 인간 검증 포인트 | | | 리더의 최종 책임 | | | Fallback Plan | | | 30일 Workflow 파일럿 실행 후보 | | ## 30일 Workflow 파일럿 실행 후보 | 주차 | 실행 내용 | 담당 | AI 활용 방식 | 점검 지표 | CH04에서 확인할 사항 | |---|---|---|---|---|---| 조건: - 교육생이 그대로 제출할 수 있을 정도로 구체적으로 작성해 주세요. - 단, 실제 현업 적용 전 리더가 검토해야 할 부분은 “리더 최종 확인 필요”로 표시해 주세요. - 이 계획은 CH04의 최종 30일 팀 성과향상 Action Plan이 아니라, 재설계 업무 1개를 대상으로 한 Workflow 파일럿 실행 후보입니다. - 팀 단위 통합 실행계획과 최종 주차별 운영계획은 CH04에서 확정합니다. - CH04에서 NotebookLM에 업로드해 Action Plan 수립에 활용할 수 있도록 Markdown 형식으로 정리해 주세요.
