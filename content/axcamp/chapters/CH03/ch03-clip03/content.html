1. 학습팀 토론 회의록 작성
첨부한 음성 파일 또는 대화문은 내가 참여한 학습팀 토론 기록입니다. 토론 주제는 “초인공 AI 시대, 리더의 고민과 역할”입니다. 이 토론 내용을 바탕으로, 이후 내 현업 팀에 적용할 성과관리 시사점을 정리하려고 합니다. 아래 형식으로 구조화된 회의록을 작성해 주세요. 출력 형식: ## 1. 회의 기본 정보 - 회의명: - 토론 주제: - 참석자: - 확인 필요 사항: ## 2. 토론 요약 | 주요 주제 | 핵심 내용 | 팀장인 나에게 주는 의미 | |---|---|---| ## 3. 토론에서 나온 리더의 고민 TOP 3 | 고민 | 왜 중요한가 | 현업 팀에서 확인할 질문 | |---|---|---| ## 4. AI에게 맡길 일 / 리더가 책임질 일 | AI에게 맡길 수 있는 일 | 리더가 직접 책임질 일 | |---|---| ## 5. 추가 논의가 필요한 사항 조건: - 발언을 그대로 나열하지 말고 주제별로 구조화해 주세요. - 학습팀 토론에서 나온 일반 의견과 현업 팀에 적용 가능한 시사점을 구분해 주세요. - 토론에서 확인되지 않은 내용은 추정하지 말고 “확인 필요”로 표시해 주세요. - 평가, 보상, 징계, 개인정보와 관련된 내용은 익명화하거나 일반화해 주세요.
2. 회의록 기반 성과관리 핵심 이슈 추출
방금 작성한 회의록을 바탕으로, 성과관리 전문가 관점에서 내가 팀장으로서 현업 팀의 성과향상을 위해 점검해야 할 핵심 이슈를 정리해 주세요. 출력 형식: ## 1. 핵심 이슈 TOP 3 | 이슈 | 토론에서 나온 근거 | 현업 팀 성과관리와의 관련성 | 리스크 수준 | |---|---|---|---| ## 2. 성과관리 장면별 시사점 | 장면 | 내가 점검할 것 | |---|---| | 목표수립 | | | 업무지시 | | | 업무배분 | | | 피드백 | | | 평가면담 | | | Speak-up | | | AI 활용 | | ## 3. 추가 확인이 필요한 내용 - 현업 팀에서 추가로 확인할 질문: - CH03에서 조직/팀 관점으로 더 진단할 이슈: - CH04에서 Action Plan으로 전환할 가능성이 있는 이슈: 조건: - “소통 강화”처럼 추상적으로 쓰지 말고, 실제 성과관리 장면으로 표현해 주세요. - 개인의 성격 문제가 아니라 리더가 점검할 행동과 장면 중심으로 정리해 주세요. - 학습팀 토론에서 나온 일반적 의견과 현업 팀에 적용 가능한 이슈를 구분해 주세요. - CH03에서 다룰 조직/팀 구조 병목은 별도로 표시해 주세요.
3. 팀장 기대행동 교차검증
방금 첨부한 문서는 “팀장의 기대행동/역할” 문서입니다. 가능하다면 CH03-3에서 만든 나의 리더 역할 프로필 Markdown도 함께 참고해 주세요. 앞서 정리한 학습팀 토론 내용, 기대행동 문서, CH03-3 리더 역할 프로필을 교차검증하여 비교해 주세요. 목적은 내가 현업 팀의 성과향상을 위해 보완해야 할 행동을 찾는 것입니다. 출력 형식: ## 1. 토론 내용과 기대행동 비교 | 토론에서 나온 내용 | 관련 기대행동 | 일치/보완/누락 | 내가 보완할 행동 | |---|---|---|---| ## 2. 내가 특히 주목해야 할 기대행동 5개 | 기대행동 | 왜 중요한가 | 현업 팀 적용 예시 | |---|---|---| ## 3. CH03-3 리더 역할 프로필과의 연결 | CH03-3 리더 역할 기준 | 기대행동 문서와의 연결 | 보완 필요 여부 | |---|---|---| ## 4. 토론에서는 부족했지만 반드시 챙겨야 할 것 - 목표/업무지시 측면: - 피드백/평가 측면: - 성장/업무배분 측면: - Speak-up 측면: - AI 활용 측면: - 공정성/책임 측면: 조건: - 기대행동 문서에 근거해 비교해 주세요. - 문서에 없는 내용은 추정하지 말고 “문서 내 확인 필요”로 표시해 주세요. - CH03-3 리더 역할 프로필과 충돌하거나 보완되는 부분이 있으면 별도 표시해 주세요. - 리더 개인의 보완 행동과 CH03에서 다룰 조직/팀 구조 이슈를 구분해 주세요. - 평가, 보상, 징계, 개인정보 관련 내용은 리더의 최종 책임과 조직 기준 확인이 필요하다고 표시해 주세요.
4. 리더 핵심 역량·스킬 및 성과관리 실행 브리프 작성
지금까지의 결과를 분석하여 내 현업 팀의 성과향상을 돕는 성과관리 전문가/보좌관 역할로 최종 실행 브리프를 작성해 주세요. ## 사용할 자료: - 학습팀 토론 회의록 - 성과관리 핵심 이슈 분석 결과 - 팀장 기대행동 문서와의 비교 결과 - 가능하다면 CH03-3 리더 역할 프로필 Markdown ## 출력 형식: ### 1. 한 줄 요약 - 내가 AI 시대에 팀장으로서 가장 먼저 바꿔야 할 것: ### 2. 리더의 핵심 역량·스킬 TOP 5 | 역량/스킬 | 필요한 이유 | 적용할 성과관리 장면 | 내가 할 행동 | |---|---|---|---| ### 3. AI에게 맡길 일 / 리더가 책임질 일 | 성과관리 장면 | AI에게 맡길 일 | 리더가 책임질 일 | |---|---|---| | 목표수립 | | | | 업무지시 | | | | 피드백 | | | | 평가면담 | | | | 회의/Speak-up | | | ### 4.
