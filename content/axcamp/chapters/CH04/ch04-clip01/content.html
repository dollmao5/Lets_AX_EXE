언제 NotebookLM을 써야 하나
1. Grounded Research
여러 소스를 묶어 소스 기반 답변을 생성합니다. 무료 계정 기준 노트북당 최대 50개 소스를 사용할 수 있으며, 계정·라이선스에 따라 한도와 기능이 달라질 수 있습니다.
2. Citation First
소스 기반 답변에는 인라인 출처가 제공되어, 어떤 자료를 근거로 답했는지 추적할 수 있습니다. 중요한 내용은 반드시 원문으로 다시 확인합니다.
3. Enterprise Lens
사내 자료, 성과관리 기준, 외부 리서치 메모를 함께 묶어 조직 맥락에 맞는 해석과 시사점을 도출합니다.
4. Studio Output
계정에서 제공되는 기능에 따라 오디오 개요, 마인드맵, 슬라이드 덱, 보고서형 요약 등 공유 가능한 산출물을 생성할 수 있습니다.
기능 사용 시 유의사항
회사·학교 계정은 조직 라이선스와 관리자 설정에 따라 기능 제공 범위와 데이터 처리 방식이 달라질 수 있습니다. 또한 AI 생성 산출물은 오류가 있을 수 있으므로, 중요한 내용은 반드시 소스 원문과 조직 기준으로 다시 확인합니다.
실제 NotebookLM 작업 화면으로 보기
왼쪽은 소스 목록, 가운데는 출처가 달린 채팅, 오른쪽은 Studio 패널입니다. NotebookLM은 읽기, 질문, 검증, 산출물 생성을 한 화면 안에서 이어가도록 돕습니다.
소스 패널
업로드한 문서와 웹 자료를 한곳에 모아 관리합니다. 어떤 자료가 분석에 포함되었는지 명확하게 확인할 수 있습니다.
채팅 패널
출처가 붙은 답변을 받아보고, 같은 문맥으로 후속 질문을 이어가며 근거와 논리를 검증합니다.
Studio 패널
계정에서 제공되는 오디오, 마인드맵, 슬라이드, 보고서형 요약 등 공유용 산출물을 만듭니다. 채팅과는 역할이 다릅니다.
Studio 패널과 채팅은 어떻게 다르나
구분 Studio 패널 채팅 패널
목적 소스를 바탕으로 공유 가능한 산출물을 정리된 형태로 생성합니다. 질문, 검증, 후속 탐색을 이어가는 대화를 수행합니다.
대표 결과 계정에서 제공되는 오디오 개요, 마인드맵, 보고서, 슬라이드 덱 등 출처가 붙은 답변, 비교표, 후속 질의응답, 검토 질문
추천 상황 보고 자료, 요약본, 교육용 산출물, 팀 공유자료가 필요할 때 왜 그런 결론이 나왔는지 더 확인하고, 원문 근거를 검증할 때
주의점 AI 생성물이므로 사실·시각·문맥 오류가 없는지 원문과 대조합니다. 출처가 있어도 최종 판단과 실행 책임은 리더에게 있습니다.
실무 감각으로 기억할 한 줄
Studio는 “정리된 결과물을 뽑는 곳”, 채팅은 “그 결과를 파고들며 검증하는 곳”입니다. 둘을 함께 써야 NotebookLM의 장점이 온전히 살아납니다.
바로 시작하기
  1. notebooklm.google.com에 접속해 새 노트북 생성 위치를 확인합니다.
  2. 소스 추가 버튼을 눌러 문서, 웹 URL, 텍스트, 이미지 등 사용 가능한 소스 유형을 확인합니다.
  3. 간단한 테스트 소스를 넣고, 소스 기반 답변에서 출처가 어떻게 표시되는지 확인합니다.
  4. Studio 패널에서 계정에 표시되는 산출물 유형을 확인합니다.
  5. 실제 CH03·CH03 산출물 업로드와 Source Map 작성은 다음 클립에서 진행합니다.

핵심 메시지
NotebookLM의 강점은 AI가 더 그럴듯하게 답하는 데 있지 않습니다. 어떤 소스를 근거로 답했는지 확인하고, 여러 자료를 한곳에 묶어 실행 가능한 판단 자료로 바꾸는 데 있습니다.
CH04에서는 CH03·CH03 산출물을 NotebookLM에 통합해 Source Map과 30일 Action Plan으로 전환합니다. 최종 판단, 민감정보 처리, 팀원에게 전달할 메시지는 리더가 책임집니다.
