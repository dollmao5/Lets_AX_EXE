# NotebookLM 소개 및 접속 방법

NotebookLM은 사용자가 넣은 자료를 중심으로 답변하고 소스 기반 답변에 출처를 제공하는 **Grounded Research 도구**입니다.

기존 개발자료의 전체 학습 Flow를 유지하여, 새 노트북 생성, 소스 패널·채팅 패널·Studio 패널, 고정 사용한도, 화면 설명, 소스 추가·선택·인라인 출처 확인을 충분히 살펴봅니다.

다음 클립에서는 **CH02 리더 역할·책임·역량 통합본, CH03 성장역량·AI 협업 통합본, Round 1~3 Team Canvas**를 하나의 노트북에 넣어 Source Map → TOP 3 → 30일 실행계획으로 연결합니다.

- **계정 원칙** — 오늘 실습은 **개인 Google 계정(Gmail이면 충분)**으로 NotebookLM에 접속합니다. **무료 계정으로도 오늘 실습을 전부 수행**할 수 있습니다 (유료 결제 불필요).

- **2단계 · 5분 룰** — 지원 담당자와 함께 5분 안에 해결되지 않으면 일단 멈추고, **옆 팀원 화면을 함께 보는 페어 진행**으로 실습을 계속합니다. 토론·판단 기여는 페어로도 동일합니다.

- **이후** — 계정은 쉬는 시간에 마저 해결하고, 본인 명의 산출물 파일은 그때 생성합니다.

### 이번 과정의 실제 필요량

필수 실습은 한 개 노트북에 핵심 소스 3~6개를 넣고 Chat·인라인 출처·Note를 사용하는 수준이므로 Standard에서도 진행할 수 있습니다. Studio 생성물은 기능 Tour에서 확인하되, 산출물 생성 횟수는 교육 계정의 남은 한도를 보고 운영합니다.

## 오늘 NotebookLM에서 경험할 것

1. Source Grounding

여러 자료를 하나의 노트북에 묶고, 필요한 소스를 선택해 자료 기반으로 질문합니다.
표준 계정은 노트북당 최대 50개 소스를 사용할 수 있으며, 한도는 플랜과 정책에 따라 달라질 수 있습니다.

2. Citation Check

답변에 표시되는 인라인 출처를 열어 근거 문맥을 확인합니다.
출처가 있더라도 중요한 판단은 반드시 소스 원문과 조직 기준으로 다시 검증합니다.

3. Cross Analysis

CH02의 리더 행동 기준과 CH03의 병목·지표·행동역량을 비교해 공통점, 충돌, 실행 우선순위를 탐색합니다.

4. Studio Output

계정에서 제공되는 Notes, Audio·Video Overview, Mind Map, Report, Data Table,
Flashcard·Quiz, Slide Deck, Infographic 등 소스 기반 산출물 위치를 확인합니다.

### 기능 사용 시 유의사항

회사·학교 계정은 조직 라이선스와 관리자 설정에 따라 기능 제공 범위와 데이터 처리 방식이 달라질 수 있습니다.
또한 Studio 산출물과 채팅 답변은 AI 생성 결과이므로, 중요한 내용은 반드시 소스 원문과 조직 기준으로 다시 확인합니다.

소스 패널

Studio 패널

계정에 제공되는 보고서, 오디오·비디오 개요, 마인드맵, 슬라이드 등 공유용 산출물을 만듭니다.

## Studio 패널과 채팅은 어떻게 다르나

|
구분 |
Studio 패널 |
채팅 패널 |

|
**목적** |
소스를 바탕으로 공유 가능한 산출물을 정리된 형태로 생성합니다. |
질문, 비교, 검증, 후속 탐색을 이어가는 대화를 수행합니다. |

|
**대표 결과** |
보고서, 데이터 표, 오디오·비디오 개요, 마인드맵, 슬라이드 덱, 인포그래픽 등 |
출처가 붙은 답변, 비교표, 후속 질의응답, 검토 질문 |

|
**추천 상황** |
팀 공유자료, 실행 요약, 브리핑 자료처럼 정리된 결과물이 필요할 때 |
결론의 이유를 파고들고, 자료 간 공통점·충돌과 원문 근거를 검증할 때 |

|
**주의점** |
사실·시각·문맥 오류가 없는지 원문과 대조합니다. |
출처가 있어도 최종 판단과 실행 책임은 리더에게 있습니다. |

### 실무 감각으로 기억할 한 줄

Studio는 **“정리된 결과물을 만드는 곳”**, 채팅은
**“그 결과의 근거를 파고들며 검증하는 곳”**입니다.
둘을 함께 써야 NotebookLM의 장점이 살아납니다.
