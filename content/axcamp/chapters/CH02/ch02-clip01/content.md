# ChatGPT Overview: 실습 환경 세팅과 핵심 기능 이해

이 클립은 오늘 사용할 ChatGPT를 단순 접속 확인으로 끝내지 않고, **전체 기능 Tour → Deep Research 상세 데모 → GPT 제작·Preview 테스트**까지 라이브 필수 경로로 경험하는 구간입니다.

참가자는 일반 Chat, 파일 첨부, 웹 검색, Deep Research, Canvas·데이터 분석·이미지·음성 등 계정에 표시되는 도구를 확인하고, 반복되는 리더십 업무를 위한 간단한 GPT를 직접 구성·테스트합니다.

화면과 메뉴명은 계정·플랜·조직 권한에 따라 달라질 수 있지만, **기능 확인 → 소스·권한 선택 → 결과 검증 → 지침 저장·테스트**의 학습 Flow는 동일합니다.

## 이번 클립에서 함께 배우는 두 가지

### 성과관리·리더십 향상 관점

ChatGPT를 통해 목표·업무지시·피드백·회의 등 성과관리 장면에서 **리더가 직접 판단할 부분과 AI가 보조할 부분**을 분석할 준비를 합니다.

### AI 기능·활용 학습

ChatGPT 접속, 새 채팅, 파일 첨부, 같은 대화에서 맥락 이어가기, 표·Markdown 출력, GPTs 메뉴의 위치와 역할을 익힙니다.

## ChatGPT를 처음 사용하는 팀장을 위한 5단계

### 기능을 외우지 말고 아래 순서만 확인합니다

① ChatGPT에 로그인합니다. ② 새 채팅을 열고 입력창을 확인합니다. ③ 웹페이지의 프롬프트를 복사해 붙여넣습니다. ④ AI가 질문하면 평소 말로 답합니다. ⑤ 필요한 표·Markdown 결과를 확인하고 안내된 파일명으로 저장합니다. 메뉴가 보이지 않으면 계정·플랜 차이일 수 있으므로 필수 Chat 실습부터 진행합니다.

⚠ 로그인·접속이 안 될 때5분 룰 · 페어 진행

- **계정 원칙** — 오늘 실습은 **개인 ChatGPT 계정**으로 진행합니다. **무료 계정으로도 오늘 실습을 전부 수행**할 수 있습니다 (유료 결제 불필요).

- **1단계** — 접속 문제가 생기면 손을 들어 **실습 지원 담당자**를 불러 주세요. 수업은 그대로 진행됩니다.

- **2단계 · 5분 룰** — 지원 담당자와 함께 5분 안에 해결되지 않으면 일단 멈추고, **옆 팀원 화면을 함께 보는 페어 진행**으로 실습을 계속합니다. 토론·판단 기여는 페어로도 동일합니다.

- **이후** — 계정은 쉬는 시간에 마저 해결하고, 본인 명의 산출물 파일은 그때 생성합니다.

## 오늘 ChatGPT에서 경험할 것

1. Chat Workbench

질문, 요약, 표 정리, 초안 작성, 후속 질문 생성처럼 짧은 왕복이 많은 업무를 ChatGPT에서 바로 처리합니다.

2. Context Input

텍스트만 입력하지 않고, 토론 대화문(텍스트), 문서, 보고서, 참고자료를 붙여 실무 맥락을 함께 제공합니다.
단, 계정·플랜에 따라 파일 업로드 개수와 용량 범위가 달라질 수 있습니다.

3. Multi-turn Analysis

같은 대화에서 근거 연결 → 팀장 기대행동 교차검증 → 「나의 핵심역량과 스킬」 작성까지 분석을 심화합니다.

4. Reusable Assistant

반복되는 성과관리 분석, 면담 준비, 회의 브리핑 흐름은 후속 실습에서 프롬프트 템플릿과 공유 GPTs로 재사용합니다.

### 오늘 수업 연결

이 챕터는 **ChatGPT 접속과 인터페이스 이해 → 대화형 프롬프팅 실습 → 자료 기반 분석 → GPTs 메뉴 확인** 순서로 이어집니다.
먼저 익숙해지고, 그다음 잘 시키고, 마지막에 반복 업무를 저장할 구조를 확인합니다.

## 접속 후 바로 확인할 4가지

-
**[chatgpt.com](https://chatgpt.com/)**에 접속해 이메일 또는 Google·Microsoft 계정으로 로그인합니다.
무료 계정으로도 오늘 필수 실습을 진행할 수 있으며, 플랜에 따라 사용 가능한 기능과 제공량이 다를 수 있습니다.

-
입력창 또는 상단에서 **모델 표시 영역**을 확인합니다.
무료 플랜은 상황에 맞는 모델이 자동 선택되는 방식이 기본이며, 유료 플랜에서는 모델 선택 메뉴가 더 넓게 열립니다.
빠른 초안 작성은 기본 상태로 충분합니다.

-
입력창 왼쪽의 **+** 또는 파일 첨부 메뉴를 확인합니다.
오늘은 위치와 사용 가능 여부를 확인하고, 후속 실습에서 Round 1·2 Team Canvas, 리더 역할 프로필, 팀장 기대행동 문서 등을 같은 대화 흐름 안에서 활용합니다.

-
실습 자료를 올리기 전에 **개인정보, 평가정보, 보상·징계 관련 민감정보**가 포함되어 있는지 확인합니다.
민감한 내용은 익명화하거나 일반화한 뒤 입력합니다.

## ChatGPT 화면 간단 소개

세 장 모두 클릭하면 크게 볼 수 있고, 확대 모달에서 홈 화면, 모델·추론 수준 메뉴, 파일 첨부 메뉴를 순서대로 확인할 수 있습니다.
실제 화면 구성과 메뉴명은 계정 유형, 플랜, OpenAI 업데이트 시점에 따라 일부 달라질 수 있습니다.
