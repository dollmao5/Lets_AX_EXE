# Gemini Overview: 실습 환경 세팅과 핵심 기능 이해

이번 클립은 Gemini의 모든 기능을 설명하는 시간이 아니라,
오늘 과정에서 사용할 **AI 실습 워크벤치**를 빠르게 이해하고 세팅하는 구간입니다.

참가자는 Gemini에서 질문을 시작하고, 파일과 회의 맥락 자료를 붙이며,
같은 대화 안에서 분석을 이어가는 기본 흐름을 확인합니다.
반복되는 성과관리 업무를 **Gems**로 저장하는 실습은 후속 클립에서 진행하며,
이번 클립에서는 메뉴 위치와 역할만 확인합니다.

이 과정에서 Gemini는 리더를 대신 판단하는 도구가 아니라,
**리더의 사고, 분석, 질문 생성, 초안 작성, 반복 업무 수행을 보조하는 AI 파트너**로 활용합니다.

## 이번 클립에서 함께 배우는 두 가지

### 성과관리·성과향상 관점

Gemini를 통해 목표·업무지시·피드백·회의 등 성과관리 장면에서 **리더가 직접 판단할 부분과 AI가 보조할 부분**을 분석할 준비를 합니다.

### AI 기능·활용 학습

Gemini 접속, 새 대화, 파일 첨부, 같은 대화에서 맥락 이어가기, 표·Markdown 출력, Gems 메뉴의 위치와 역할을 익힙니다.

## Gemini를 처음 사용하는 팀장을 위한 5단계

### 기능을 외우지 말고 아래 순서만 확인합니다

① Gemini에 로그인합니다. ② 새 대화를 열고 입력창을 확인합니다. ③ 웹페이지의 프롬프트를 복사해 붙여넣습니다. ④ AI가 질문하면 평소 말로 답합니다. ⑤ 필요한 표·Markdown 결과를 확인하고 안내된 파일명으로 저장합니다. 메뉴가 보이지 않으면 계정·라이선스 차이일 수 있으므로 필수 Chat 실습부터 진행합니다.

## 오늘 Gemini에서 경험할 것

1. Chat Workbench

질문, 요약, 표 정리, 초안 작성, 후속 질문 생성처럼 짧은 왕복이 많은 업무를 Gemini에서 바로 처리합니다.

2. Context Input

텍스트만 입력하지 않고, 회의 오디오, 문서, 보고서, 참고자료를 붙여 실무 맥락을 함께 제공합니다.
단, 계정·라이선스·관리자 설정에 따라 파일 업로드 가능 범위가 달라질 수 있습니다.

3. Multi-turn Analysis

같은 대화에서 회의록 작성 → 핵심 이슈 추출 → 기대행동 비교 → 실행 브리프 작성까지 분석을 심화합니다.

4. Reusable Assistant

반복되는 성과관리 분석, 면담 준비, 회의 브리핑 흐름은 후속 실습에서 Gems로 저장해 재사용합니다.

### 오늘 수업 연결

이 챕터는 **Gemini 접속과 인터페이스 이해 → 대화형 프롬프팅 실습 → 자료 기반 분석 → Gems 메뉴 확인** 순서로 이어집니다.
먼저 익숙해지고, 그다음 잘 시키고, 마지막에 반복 업무를 저장할 구조를 확인합니다.

## 접속 후 바로 확인할 4가지

-
**[gemini.google.com/app](https://gemini.google.com/app)**에 접속해 Google 계정으로 로그인합니다.
회사 또는 학교 계정은 라이선스와 관리자 설정에 따라 사용 가능한 기능이 다를 수 있습니다.

-
하단 입력창 또는 상단 메뉴에서 **모델/도구 선택 영역**을 확인합니다.
빠른 초안 작성은 기본 모델로 충분하지만, 긴 문서 분석, 회의 오디오 분석, 심층 조사는 상위 모델 또는 Deep Research 기능이 더 적합할 수 있습니다.

-
입력창 주변의 **+** 또는 파일 첨부 메뉴를 확인합니다.
오늘은 위치와 사용 가능 여부를 확인하고, 후속 실습에서 회의 오디오, 회의록, 팀장 기대행동 문서 등을 같은 대화 흐름 안에서 활용합니다.

-
실습 자료를 올리기 전에 **개인정보, 평가정보, 보상·징계 관련 민감정보**가 포함되어 있는지 확인합니다.
민감한 내용은 익명화하거나 일반화한 뒤 입력합니다.

## Gemini 화면 간단 소개

세 장 모두 클릭하면 크게 볼 수 있고, 확대 모달에서 홈 화면, 모델/도구 선택, 파일 업로드 메뉴를 순서대로 확인할 수 있습니다.
실제 화면 구성과 메뉴명은 계정 유형, 라이선스, Google 업데이트 시점에 따라 일부 달라질 수 있습니다.

## 실습 운영 원칙

|
원칙 |
실습에서의 적용 |

|
**한 대화창에서 맥락 누적** |
새 질문마다 처음부터 다시 설명하지 않고, 같은 대화에서 자료와 답변을 누적합니다. |

|
**프롬프트는 업무 위임서** |
역할, 맥락, 분석 기준, 출력 형식, 제한 조건을 함께 지정합니다. |

|
**AI는 보조, 리더는 판단** |
AI는 초안·요약·비교·질문 생성을 지원하고, 최종 판단과 피드백 책임은 리더가 집니다. |

|
**민감정보 보호** |
평가, 보상, 징계, 개인정보 관련 내용은 익명화·일반화하고 조직 기준 확인이 필요한 항목으로 구분합니다. |

|
**산출물 재사용** |
후속 실습에서 좋은 결과물은 Markdown, 표, Gem 지침 형태로 저장해 다시 활용합니다. |

### 핵심 메시지

Gemini는 답을 대신 내려주는 도구가 아니라,
**리더가 더 정확하게 질문하고, 더 빠르게 분석하고, 더 일관되게 실행하도록 돕는 업무 파트너**입니다.
이번 클립의 목적은 산출물을 만드는 것이 아니라,
이후 실습에서 안정적으로 사용할 Gemini 워크벤치를 확인하는 것입니다.
