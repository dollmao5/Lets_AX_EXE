ChatGPT Overview: 실습 환경 세팅과 핵심 기능 이해

이번 클립은 ChatGPT의 모든 기능을 설명하는 시간이 아니라,
오늘 과정에서 사용할 AI 실습 워크벤치를 빠르게 이해하고 세팅하는 구간입니다.

참가자는 ChatGPT에서 질문을 시작하고, 파일과 회의 맥락 자료를 붙이며,
같은 대화 안에서 분석을 이어가는 기본 흐름을 확인합니다.
반복되는 성과관리 업무를 GPTs와 프롬프트 템플릿으로 재사용하는 실습은 후속 클립에서 진행하며,
이번 클립에서는 메뉴 위치와 역할만 확인합니다.

이 과정에서 ChatGPT는 리더를 대신 판단하는 도구가 아니라,
리더의 사고, 분석, 질문 생성, 초안 작성, 반복 업무 수행을 보조하는 AI 파트너로 활용합니다.

이번 클립에서 함께 배우는 두 가지

성과관리·리더십 향상 관점

ChatGPT를 통해 목표·업무지시·피드백·회의 등 성과관리 장면에서 리더가 직접 판단할 부분과 AI가 보조할 부분을 분석할 준비를 합니다.

AI 기능·활용 학습

ChatGPT 접속, 새 채팅, 파일 첨부, 같은 대화에서 맥락 이어가기, 표·Markdown 출력, GPTs 메뉴의 위치와 역할을 익힙니다.

ChatGPT를 처음 사용하는 팀장을 위한 5단계

기능을 외우지 말고 아래 순서만 확인합니다

① ChatGPT에 로그인합니다. ② 새 채팅을 열고 입력창을 확인합니다. ③ 웹페이지의 프롬프트를 복사해 붙여넣습니다. ④ AI가 질문하면 평소 말로 답합니다. ⑤ 필요한 표·Markdown 결과를 확인하고 안내된 파일명으로 저장합니다. 메뉴가 보이지 않으면 계정·플랜 차이일 수 있으므로 필수 Chat 실습부터 진행합니다.

오늘 ChatGPT에서 경험할 것

1. Chat Workbench

질문, 요약, 표 정리, 초안 작성, 후속 질문 생성처럼 짧은 왕복이 많은 업무를 ChatGPT에서 바로 처리합니다.

2. Context Input

텍스트만 입력하지 않고, 토론 전사 텍스트, 문서, 보고서, 참고자료를 붙여 실무 맥락을 함께 제공합니다.
단, 계정·플랜에 따라 파일 업로드 개수와 용량 범위가 달라질 수 있습니다.

3. Multi-turn Analysis

같은 대화에서 회의록 작성 → 핵심 이슈 추출 → 기대행동 비교 → 실행 브리프 작성까지 분석을 심화합니다.

4. Reusable Assistant

반복되는 성과관리 분석, 면담 준비, 회의 브리핑 흐름은 후속 실습에서 프롬프트 템플릿과 공유 GPTs로 재사용합니다.

오늘 수업 연결

이 챕터는 ChatGPT 접속과 인터페이스 이해 → 대화형 프롬프팅 실습 → 자료 기반 분석 → GPTs 메뉴 확인 순서로 이어집니다.
먼저 익숙해지고, 그다음 잘 시키고, 마지막에 반복 업무를 저장할 구조를 확인합니다.

접속 후 바로 확인할 4가지

-
chatgpt.com에 접속해 이메일 또는 Google·Microsoft 계정으로 로그인합니다.
무료 계정으로도 오늘 필수 실습을 진행할 수 있으며, 플랜에 따라 사용 가능한 기능과 제공량이 다를 수 있습니다.

-
입력창 또는 상단에서 모델 표시 영역을 확인합니다.
무료 플랜은 상황에 맞는 모델이 자동 선택되는 방식이 기본이며, 유료 플랜에서는 모델 선택 메뉴가 더 넓게 열립니다.
빠른 초안 작성은 기본 상태로 충분합니다.

-
입력창 왼쪽의 + 또는 파일 첨부 메뉴를 확인합니다.
오늘은 위치와 사용 가능 여부를 확인하고, 후속 실습에서 토론 전사 텍스트, 회의록, 팀장 기대행동 문서 등을 같은 대화 흐름 안에서 활용합니다.

-
실습 자료를 올리기 전에 개인정보, 평가정보, 보상·징계 관련 민감정보가 포함되어 있는지 확인합니다.
민감한 내용은 익명화하거나 일반화한 뒤 입력합니다.

핵심 메시지

ChatGPT는 답을 대신 내려주는 도구가 아니라,
리더가 더 정확하게 질문하고, 더 빠르게 분석하고, 더 일관되게 실행하도록 돕는 업무 파트너입니다.
