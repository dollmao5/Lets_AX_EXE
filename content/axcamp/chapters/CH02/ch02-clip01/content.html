오늘 ChatGPT에서 경험할 것
1. Chat Workbench
질문, 요약, 표 정리, 초안 작성, 후속 질문 생성처럼 짧은 왕복이 많은 업무를 ChatGPT에서 바로 처리합니다.
2. Context Input
텍스트만 입력하지 않고, 토론 대화문(텍스트), 문서, 보고서, 참고자료를 붙여 실무 맥락을 함께 제공합니다. 단, 계정·플랜에 따라 파일 업로드 개수와 용량 범위가 달라질 수 있습니다.
3. Multi-turn Analysis
같은 대화에서 회의록 작성 → 핵심 이슈 추출 → 기대행동 비교 → 실행 브리프 작성까지 분석을 심화합니다.
4. Reusable Assistant
반복되는 성과관리 분석, 면담 준비, 회의 브리핑 흐름은 후속 실습에서 프롬프트 템플릿과 공유 GPTs로 재사용합니다.
오늘 수업 연결
이 챕터는 ChatGPT 접속과 인터페이스 이해 → 대화형 프롬프팅 실습 → 자료 기반 분석 → GPTs 메뉴 확인 순서로 이어집니다. 먼저 익숙해지고, 그다음 잘 시키고, 마지막에 반복 업무를 저장할 구조를 확인합니다.
접속 후 바로 확인할 4가지
  1. chatgpt.com에 접속해 이메일 또는 Google·Microsoft 계정으로 로그인합니다. 무료 계정으로도 오늘 필수 실습을 진행할 수 있으며, 플랜에 따라 사용 가능한 기능과 제공량이 다를 수 있습니다.
  2. 입력창 또는 상단에서 모델 표시 영역을 확인합니다. 무료 플랜은 상황에 맞는 모델이 자동 선택되는 방식이 기본이며, 유료 플랜에서는 모델 선택 메뉴가 더 넓게 열립니다. 빠른 초안 작성은 기본 상태로 충분합니다.
  3. 입력창 왼쪽의 + 또는 파일 첨부 메뉴를 확인합니다. 오늘은 위치와 사용 가능 여부를 확인하고, 후속 실습에서 Round 1·2 Team Canvas, 리더 역할 프로필, 팀장 기대행동 문서 등을 같은 대화 흐름 안에서 활용합니다.
  4. 실습 자료를 올리기 전에 개인정보, 평가정보, 보상·징계 관련 민감정보가 포함되어 있는지 확인합니다. 민감한 내용은 익명화하거나 일반화한 뒤 입력합니다.
ChatGPT 화면 간단 소개

세 장 모두 클릭하면 크게 볼 수 있고, 확대 모달에서 홈 화면, 모델·추론 수준 메뉴, 파일 첨부 메뉴를 순서대로 확인할 수 있습니다. 실제 화면 구성과 메뉴명은 계정 유형, 플랜, OpenAI 업데이트 시점에 따라 일부 달라질 수 있습니다.

GPT Builder / 새 채팅설정형리더십 질문 코치 최소 지침
당신은 팀장 대상 ‘리더십 질문 코치’입니다. 목적은 답을 대신 결정하는 것이 아니라, 팀장이 실제 업무 장면·근거·이해관계자·책임 경계를 더 정확히 확인하도록 돕는 것입니다. [진행 원칙] - 한 번에 질문 1개만 합니다. - 답변에 없는 사실·수치·조직 정책을 만들지 않습니다. - 목표수립, 업무지시, 회의, 1:1, 피드백, 평가 중 적용 장면을 먼저 확인합니다. - AI가 보조할 일과 리더가 직접 판단·설명·책임질 일을 분리합니다. - 개인정보·평가·보상·징계·고객 식별정보 입력을 요청하지 않습니다. - 마지막에는 ‘확인된 사실 / 리더 해석 / 가설 / 팀원·조직 확인 필요’를 구분해 표로 정리합니다.
